# Dashboards: Watch settings help text (#139)

There is no server-side dashboard, because there is no telemetry, by design. These are the views that exist for this change:

| View | Where | What it shows for this change |
|---|---|---|
| Watch settings screen | phone app | the help line under each row; the explanation at the top of each value list; the shortcut action descriptions |
| Store screenshots | `fastlane/metadata/android/en-US/images/phoneScreenshots/2.png`, `3.png` | the screen as shipped, regenerated from the code |
| GitHub | issues, release downloads | user reports about unclear or wrong help text; v0.0.84 adoption |
| Play Console | closed test | installs, crashes and ANRs (Android vitals), tester feedback |
| F-Droid | package page | v0.0.84 build status |
